# Capsule Stash v1.0.0

매일 쓰는 메뉴바 지식 저장소, 첫 정식판.

## 수집
- Share 확장 수신함 (Inbox 문서로 편입)
- Safari Web Extension (현재 탭 저장, URL scheme 채널)
- `capsule://search·save·open` + Shortcuts 액션 2종

## 안전
- 일괄 내보내기 (JSON/MD 왕복) + 자동 백업 (1일 1회·7세대·복원)

## 꺼내기

- Raycast 확장 (검색·클립보드 저장)
- 스마트 그룹 (검색 조건 저장) + 중첩 태그 (`부모/자식`)

## 설치
- 아래 ZIP → 압축 해제 → `~/Applications` → 우클릭→열기로 첫 실행
